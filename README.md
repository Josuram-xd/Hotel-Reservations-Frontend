# Hotel Reservations - Frontend

Web app for the hotel reservation system (UI in Spanish). React, Vite, TypeScript, Tailwind, GSAP.

## Screens

1. Room search by dates with availability.
2. Room selection with dynamic price preview.
3. Booking form with guest data.
4. Reservation panel: add services, summary, check-in and check-out.
5. Final invoice generated by the server.

## Run locally

```bash
cp .env.example .env
npm install
npm run dev
npm test
npm run build
```

## Environment variables

| Name | Default | Purpose |
|---|---|---|
| `VITE_API_URL` | `http://localhost:8080` | Backend base URL (Railway URL in production) |

## Deployment

Vercel. Set `VITE_API_URL` to the Railway backend URL; `vercel.json` rewrites routes to `index.html`.
See `TASKS.md` for the work plan and `DESIGN.md` for the visual direction.
